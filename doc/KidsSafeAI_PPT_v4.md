# 슬라이드 2: 시스템 개요
---
### KidsSafe PWA
- **위치 추적**: GPS 기반 실시간 위치 모니터링 (3초 간격)
- **위험 탐지**: 경고범위(15m) 미션 발동, 주의범위(100m) 알림 표시
- **미션 시스템**: 4단계 안전 미션 (흔들기/회전/음성인식 랜덤)
- **TTS 음성 출력**: 위험/주의 알림 + 미션 단계별 음성 안내
- **알림**: 진동 0.5초×5회(모바일) + 브라우저 알림 + 화면 배너
- **PWA**: 오프라인 지원, HTTPS 서비스 가능

### 기술 스택
- **프론트엔드**: HTML5, CSS3, Vanilla JavaScript (ES6 Modules)
- **지도**: Leaflet.js + OpenStreetMap
- **데이터 파이프라인**: Python (CSV → JSON → 분석)
- **음성**: Web Speech API (TTS) + webkitSpeechRecognition (음성인식)
- **저장**: localStorage (설정), Service Worker (오프라인 캐싱)
- **배포**: GitHub Pages

# 슬라이드 4: 데이터 파이프라인
---
### 3-Layer 자동화 구조

**Layer 1: 원천 CSV → JSON 변환**
- convert_schools.py → schools.json (115개)
- convert_protection_zones.py → protection_zones.json (61개, CCTV)
- convert_crosswalks.py → crosswalks.json (1057개)
- convert_accidents.py → accidents.json (135개, 692건)

**Layer 2: 통합**
- merge_locations.py → locations.json (1368개, 유효좌표 100%)

**Layer 3: 분석**
- school_safety_grader.py → 113개 학교 안전등급 (A~F)
- accessibility_score.py → 1057개 횡단보도 접근성 점수

### 실행
```bash
python run_pipeline.py  # 7단계, 약 3초
```

# 슬라이드 6: 핵심 기능 - GPS 탐지
---
### checkProximity() 로직

| 구분 | 일반 횡단보도 | 초등학교앞 횡단보도 | 사고다발지역 |
|------|-------------|-----------------|------------|
| 경고(15m) | 🟡 주의 알림 | 🔴 위험 알림 + 미션 | 🔴 위험 알림 + 미션 |
| 주의(100m) | 🟡 알림 | 🔴 알림 | 🔴 알림 |
| +3m 리셋 | 동일 | 동일 | 동일 |

### 초등학교 주변 횡단보도 DANGER 승격
- 초등학교 30곳 기준 반경 100m 이내 횡단보도 55개 자동 분류
- 일반 횡단보도(1,002개)는 주의(🟡), 초등학교앞(55개)은 위험(🔴)으로 차등 대응
- 초등학교 자체는 알림 대상 아님 (건물이 위험이 아니라 주변 횡단보도가 핵심)

### +3m Reset Zone
```
경고범위(15m) 이내 → 미션 발동 + 알림
경고범위+3(18m) 이내 → 상태 유지 (재진동 방지)
18m 밖 → 미션 리셋
```

- 사용자 설정 슬라이더로 경고/주의 범위 자유 조정
- 모든 레이어 마커는 사용자 위치 기준 거리순 정렬

# 슬라이드 7: 핵심 기능 - 미션 시스템
---
### 횡단보도/위험지역 15m 이내 자동 발동

**4단계 미션 — 매 단계마다 랜덤 방식 지정**

| 단계 | 미션 내용 | 가능한 방식 (랜덤) |
|------|----------|-----------------|
| 1/4 | 🟢 초록불이 켜졌어요! | 📱 흔들기 / 🎤 "초록불" |
| 2/4 | 👀 좌우를 살펴봐! | 📱 흔들기 / 🎤 "확인 완료" |
| 3/4 | 👁️ 좌우 회전하며 살피기 | 🔄 회전 / 🎤 "회전했어요" |
| 4/4 | ✅ 다 건넜어! | 📱 흔들기 / 🎤 "다 건넜어요" |

**음성 인식 (Android Chrome 전용)**
- `webkitSpeechRecognition` + ko-KR, 키워드 매칭 방식
- ⚠️ **iOS Safari**: Web Speech Recognition API 미지원 → 현재 흔들기/회전만 자동 필터링
- 향후 업데이트: iOS 네이티브(SFSpeechRecognizer) 연동 또는 차선책 적용 예정

**TTS 음성 출력**
- 미션 시작: "횡단보도에 진입했습니다. 미션을 시작합니다."
- 각 단계 진입 시: 현재 미션 텍스트 읽어주기
- 미션 완료: "미션 완료! 안전하게 건넜어요!"
- 위험/주의 알림: "위험! [위치]까지 [거리]미터"
- ⚠️ **iOS Safari**: 사용자 제스처 내에서만 speak() 허용 → GPS 콜백 TTS는 제한적
- 향후 업데이트: iOS 네이티브 연동 또는 Web Speech API 우회 기법 적용 예정

**진동 0.5초 × 5회**
- 위험/주의 알림, 미션 시작, 미션 완료 시 진동
- 미션 단계 성공 시: 짧은 진동 1회 (300ms)

**기기 대응**
- iOS 13+: DeviceMotionEvent.requestPermission()
- Android: accelerationIncludingGravity fallback
- 데스크톱: Enter/Space 스킵 가능
